# Migration to 1.2.1

No world-data migration is required. Existing campaign-authored strings remain valid and are displayed as entered. Shipped records now reference Foundry localization keys internally.

Use Foundry’s global Language Preference to select a supported language. No module-specific language setting exists. Existing image overrides, imported Actors, prototype-token textures, folders, Items, Journals, provider registrations, and stable IDs are preserved.
