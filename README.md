# Runyth Hunter's Bestiary - D&D 5e 2024

Current release: **1.2.2**. Requires Runyth Hunter's Bestiary 1.4.2 and D&D 5e 5.3.3.

## 1.2.0 actor-image feature

- Quarry thumbnails use the effective image owned by Runyth Hunter's Bestiary core.
- A GM can click a quarry thumbnail to open Foundry's standard image FilePicker.
- Imported and updated Actors receive the same image as both Actor portrait and prototype-token texture.
- Existing core world overrides are reapplied during later Actor updates.
- The existing **Import everything** workflow remains available for Actors and harvest Items.

## Installation

Install Runyth Hunter's Bestiary 1.4.2 first. Stop Foundry, replace the complete `Data/modules/runyth-hunters-bestiary-dnd5e-2024` directory with the contents of `runyth-hunters-bestiary-dnd5e-2024-v1.2.2.zip`, then restart Foundry.

See [`docs/ACTOR-IMAGES.md`](docs/ACTOR-IMAGES.md) for the source and installed-world workflows.
## Localization

This module uses Foundry VTT’s standard global localization system. Select the active language through Foundry’s **Language Preference** setting; there is no dashboard-specific selector. English is the fallback/default language. See [`docs/LOCALIZATION.md`](docs/LOCALIZATION.md) to add another language.
